# Cisco Packet Tracer Lab: Static Routing & DHCP

* **Course**: Computer Networks Lab (CN Lab)
* **Date**: 14/10/26[cite: 6]
* **Objective**: Perform Static Routing and configure DHCP across multiple subnets ($N_1, N_2, N_3$) using Cisco Routers ($R_1, R_2, R_3$)[cite: 6].

## Topology Overview
* **Router 1 (R1)**: Manages Subnet $N_1$ (`192.168.1.0/24`) with local DHCP pool and serial link to R2.
* **Router 2 (R2)**: Manages Subnet $N_2$ (`192.168.2.0/24`), acts as core router connecting $R_1$ and $R_3$.
* **Router 3 (R3)**: Manages Subnet $N_3$ (`192.168.3.0/24`) with static routes and DHCP pool.
